# Jot

Personal notes and to-do PWA.

## Setup for running

1. Replace `YOUR_CLIENT_ID` in `app.js` with your Google Cloud OAuth 2.0 Web Client ID.
2. Enable Google Drive API and add the published URL to Authorized JavaScript origins.
3. Host on GitHub Pages: Settings → Pages → Deploy from branch `main` / `/ (root)`.
4. Add the resulting URL (https://tedwon.github.io/jot/) to the home screen on your phones.

Notes sync via Google Drive for the account `iamtedwon@gmail.com` only.
